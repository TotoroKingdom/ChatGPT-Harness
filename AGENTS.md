Current implementation truth comes from current source code, tests, manifests, and `wiki/**`.

Do not read or use `docs/archive/**` unless the user explicitly asks for historical documentation.

`docs-codex/**` contains V2 planning and execution records. V2 is completed and accepted; those files are retained for historical implementation context and must not be treated as evidence of current status.

When documentation conflicts, use this priority: current source/tests/manifests → `wiki/**` → `docs-codex/**` → `docs/archive/**`.
