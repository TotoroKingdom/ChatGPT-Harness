# 下一版本开发入口

`docs-codex/` 是下一版本的文档工作区。当前暂不生成新版本 PRD、ARCHITECTURE、ROADMAP、SPEC、PLAN 或 TASKS。

开始新版本工作前，先读取当前源码、Tests（测试）、Manifests（清单）、最新 `wiki/**` 和仓库指引。当前实现事实以源码、Tests、Manifests 和最新 Wiki 为准；本目录中的未来规划材料不代表功能已经实现。

V3 的开发、测试、验收和设计历史资料已归档至 [`docs/archive/v3-2026-10/`](../docs/archive/v3-2026-10/)，仅供历史参考。
